# Malbolge in LangLib

Ben Olmstead's 1998 language, named after the eighth circle of Hell and
designed to be nearly impossible to program in; the first program was found
by a search procedure two years after release. The full specification,
history, tables, and the exact semantic choices (including every place the
printed spec and the reference interpreter disagree) are in
[docs/malbolge/spec.md](../../../docs/malbolge/spec.md).

## Modules

* `Syntax.lean`: the machine vocabulary. A Malbolge "AST" is the loaded
  59049-word memory image (`Image`); the eight instructions (`Instr`) and
  their position-dependent decoding, the ternary word operations (`rotR`,
  `crz`), and the encryption table (`xlat2`) live here.
* `Parser.lean`: the loader (`load`), a faithful copy of the reference
  interpreter's, including its famous oversight (non-printable bytes are
  stored unchecked). Errors report line, column, and load address.
* `Semantics.lean`: the pure, fuel-based evaluator; one fuel unit per
  execution cycle.
* `Main.lean`: the standalone runner.

## Running

```
lake exe malbolge [--fuel N] file.mal
```

`.mal` is the customary extension (`.mb` is the other one seen in the
wild). Input is read from stdin, output written to stdout. Exit codes:
0 halt, 1 runtime error, 2 out of fuel, 3 parse or usage error. Note that
two of the classics below never halt by design; give them a modest
`--fuel`.

## Examples ([Langlib/Examples/Malbolge/](../../Examples/Malbolge/))

Malbolge programs cannot contain comments (every non-whitespace character
is loaded into memory and checked), so attribution lives here:

| File | What it does | Origin |
|------|--------------|--------|
| `nop.mal` | no-op, halt; two characters, the shortest program that runs | credited to Ben Olmstead in the Esoteric File Archive; the language author's own, and apparently his only one |
| `answer.mal` | prints `42`, then halts | `mtve`, via the Esoteric File Archive; 28 straight-line instructions, no jumps |
| `hello.mal` | prints `HEllO WORld`, then halts | Andrew Cooke, 2000; the first Malbolge program, generated by his Lisp beam search |
| `hello-world.mal` | prints `Hello, world.`, then halts | authorship uncertain; the version that circulates today, reproduced by Wikipedia, which cites a 2021 gist by Kamila Szewczyk |
| `cat.mal` | copies input to output, then prints byte 168 forever | esolangs wiki (CC0) |
| `truth.mal` | truth-machine: `0` prints `0` and halts, `1` prints `1` forever | esolangs wiki (CC0) |
| `scheffer-cat.mal` | copies input to output, then prints byte 168 forever | Lou Scheffer, 2004 (public domain); the first cat program |
| `99bottles.mal` | prints the whole song (11459 bytes), then halts | Hisashi Iizawa, Toshiki Sakabe, Masahiko Sakai, Keiichirou Kusakari and Naoki Nishida, 2005, via the esolangs wiki (CC0); the first Malbolge program with real loops and conditionals |

`99bottles.mal` is 22561 instructions and takes between ten and twenty
million machine cycles, comfortably inside the runner's default fuel.

`scheffer-cat.mal` exploits the loader oversight: it contains bytes 189
and 228, which only load because the reference interpreter forgets to
check non-printable characters. Scheffer distributed it uuencoded; since
our runner reads program files as UTF-8 text, the file here stores those
byte values as UTF-8 code points (the loaded memory image is identical,
but the file is not byte-for-byte Scheffer's, and the C reference
interpreter reads it differently).

## Tests

Golden tests live in [Langlib/Tests/Malbolge.lean](../../Tests/Malbolge.lean)
(run with `lake test` from the repository root): the examples above,
micro-programs for each word operation verified byte-for-byte against
Olmstead's interpreter, EOF handling, the non-printable spin, divergence,
and the loader errors. The never-halting cats are golden-tested through a
wrapper that compares the echoed prefix of their output.
