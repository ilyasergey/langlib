# Velato

Velato (Daniel Temkin, 2009) is a programming language whose source code is a
MIDI file: the pitches, and the order they sound in, are the program.
Commands are intervals from a *command root* that the composer can move at
will, so a program keeps its meaning under transposition — and so a piece of
music is, if the intervals happen to fall right, also a program.

The language specification, every semantic decision this implementation
makes and its source, and the example programs engraved as sheet music, are
in [`docs/velato/spec.md`](../../../docs/velato/spec.md).

## Running

```
lake exe velato Langlib/Examples/Velato/hello.vel
```

A program may be a MIDI file or langlib's text form. The runner tells them
apart by looking at the file: a Standard MIDI File begins with `MThd`, and
anything else is read as whitespace-separated scientific pitch names. The
examples here are kept as text — `.vel` — because a repository cannot review
a binary, which is the same decision this library makes for Piet.

Besides running a program, the runner will show it:

| flag | |
| --- | --- |
| `--ast` | print the program as structured pseudocode |
| `--notes` | print each note with its interval and its role |
| `--sheet FILE` | engrave as sheet music: `.pdf`, `.svg` or `.ppm` |
| `--midi FILE` | write a Standard MIDI File |
| `--wav FILE` | synthesise audio (16-bit PCM, 44.1 kHz, mono) |
| `--plain` | engrave without the note-role labels |
| `--scale N` | multiply the raster size (`.ppm` only) |

`scripts/velato-audio.sh` renders a program and plays it with whatever the
machine already has.

## The modules

| file | |
| --- | --- |
| `Note.lean` | pitches, note names, and the two readings of an interval |
| `Syntax.lean` | the abstract syntax |
| `Parser.lean` | notes to syntax, recording what each note was |
| `Semantics.lean` | the pure fuel-based reference interpreter |
| `Stability.lean` | completed runs are a fixed point of more fuel |
| `Trace.lean` | the run's recorded I/O events are exactly what it read and wrote |
| `Faithful.lean` | a halting run depends only on the bytes its trace claims |
| `Emit.lean` | syntax back to notes, with voice leading |
| `Midi.lean` | Standard MIDI Files, both directions |
| `Sheet.lean` | engraving a program onto a staff |
| `Render.lean` | that engraving as PDF, SVG, or a raster image |
| `Audio.lean` | synthesising a program to a WAV file |
| `Main.lean` | the runner |

Everything here is free of Mathlib and cslib, so it compiles fast. The
Turing-completeness proof, which needs both, is in
[`Langlib/Computability/Velato.lean`](../../Computability/Velato.lean) and
explained in
[`docs/computability-velato.md`](../../../docs/computability-velato.md).
That file also registers Velato's `TraceLang` instance, built from
`Trace.lean` and `Faithful.lean`, which is what lets the Turpentine backend
for Velato be proved correct *behaviourally*, input included:
[`Langlib/Languages/Turpentine/Certified/BespokeVelato.lean`](../Turpentine/Certified/BespokeVelato.lean),
with the fragment spelled out in
[`docs/velato/compiler.md`](../../../docs/velato/compiler.md).

## Two things worth knowing before reading the code

**The parser records the note roles.** `parseNotesAnnotated` returns, beside
the program, a label per note saying what the parser made of it. Those
labels are what appear under the staff on an engraved sheet and in
`--notes`. They live in the parser rather than in a second pass on purpose:
a separate scanner that re-derived the roles from the same tables would be a
second grammar, free to drift from the first.

**Writing notes is a search, not a function.** Velato leaves a great deal
underdetermined — octave everywhere but a variable's name, major or minor
inside expressions, where to put the command root, and how many no-op notes
to sprinkle between statements. `Emit.lean` spends that freedom on making
the result sound like music, and `emitFollowing` spends it on making the
result resemble a given melody. Both are checked against the parser: the
tests round-trip every program the encoder writes, from every root in the
octave.

## Examples and tests

[Examples](../../Examples/Velato/) — twenty-two of them, all but one
generated by [`scripts/gen-velato-examples.lean`](../../../scripts/gen-velato-examples.lean)
and each round-tripped through the parser before it is written.
[Tests](../../Tests/Velato.lean) are hand-written note sequences that
exercise the interval tables directly, encoded sequences that pin down
precedence and promotion, and the examples run as a reader would run them.
