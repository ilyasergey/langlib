Where things stand

langlib documentation

What exists, per language: the specification, the parser, the interpreter, the examples and tests, the runner, the compiler from Turpentine, and the proof that the compiler is correct. The last column is the long game.

Per-language specifications live in docs/<langname>/spec.md; compiler notes (once a Turpentine compiler exists for the language) in docs/<langname>/compiler.md.

Project documents#

  • PLAN.md: the staged workplan (agents: keep it current).
  • PROGRESS.md: dated progress log.
  • TESTING.md: the two test layers, and what to install for differential testing per language.
  • ROADMAP.md: candidate languages and instructions for adding one.
  • RELATED.md: related efforts elsewhere.
  • verification.md (Stage 6): the compiler verification pipeline design.
